# newsletter-t42

Hospedagem de imagens da **Transmissão 42**, a newsletter da 42 São Paulo.

Cada edição tem sua pasta. As imagens são referenciadas por URL direta no HTML
do e-mail disparado pelo ActiveCampaign.

## Estrutura

```
t42-017/    imagens da edição 017 — "Token é a nova internet discada"
```

## Como usar a URL de uma imagem

```
https://raw.githubusercontent.com/matav42/newsletter-t42/main/<pasta>/<arquivo>
```

Nome de arquivo sem espaço, sem vírgula e sem acento.
